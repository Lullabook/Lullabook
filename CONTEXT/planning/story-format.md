# Story Format & Scope

Product decisions on what a Story/Storybook *is* as a reading artifact. Reversible
(not ADRs), but they pin cost, layout, and the generation prompt.

## Tonal scope

**Broad, any-occasion personalized stories** — milestones, lessons, holidays, and
bedtime. Bedtime is one prominent theme, not the whole product. Rationale: the
subscription model ([ADR-0009](../docs/adr/0009-subscription-monetization.md))
needs recurring reasons to generate; a broad scope maximizes occasions. (The
"Lullabook" working name is provisional and should not narrow the product.)

## Format (v1)

- **Length:** fixed ~12 Pages per Storybook (predictable cost + simple layout).
- **Text density:** 1–3 short, simple sentences per Page.
- **Audience:** read-aloud, tuned for ages ~1–6 (the parent reads to the child).
- **Language:** English only in v1; localization later.

## Roadmap note

This format covers the **Text + Illustration** Storybook (v1). Audio (v2) narrates
the same text; Video (v3) animates text + illustration + audio. See the medium
roadmap in [CONTEXT.md](../CONTEXT.md).
