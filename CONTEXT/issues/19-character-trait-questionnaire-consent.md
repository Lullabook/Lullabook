# 19 — Character creation via Trait Questionnaire + light consent

Status: shipped
Photo-free Character creation from a Trait Questionnaire (name, nickname, relationships, favorites, songs) — no photos, no LoRA, no biometric. A real-child Character requires a light consent checkpoint (jurisdiction-aware notice + single guardian attestation, a lightweight Consent-receipt variant); a fully-fictional Character skips it; jurisdiction config can escalate to the heavy biometric gate with no code change. Characters are Family-scoped under the same RLS as Personas. Later extended (not replaced) by Character→Persona upgrade (21).
