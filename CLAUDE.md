## Report language

Write all reports to the user in ASD-STE100 Simplified Technical English.

Rules:

- Write short sentences. Use a maximum of 20 words in a procedural sentence and
  a maximum of 25 words in a descriptive sentence.
- Write one instruction in one sentence.
- Use the active voice. Do not use the passive voice.
- Use only one meaning for each word. Use the approved technical name for each
  part, file, command, and service.
- Use articles ("a", "an", "the") always.
- Use simple verb tenses: the present tense, the past tense, and the future
  tense. Do not use participle phrases as adjectives.
- Do not use idioms, metaphors, jargon, or humor.
- Do not omit words to make a sentence shorter.
- Write warnings and cautions before the related instruction, not after it.
- Use lists for a sequence of steps. Use a table for data.

This rule applies to the text you write to the user. It does not apply to source
code, code comments, commit messages, or documents in `CONTEXT/`.
