# PRD v5 — "Maya's World" Revamp

Status: shipped — this is the current domain model (full glossary in CONTEXT.md).

Still-binding decisions:
- **Household** = account/billing/consent boundary. **Baby** = starring child (a
  Household has one or more; R1 restricts to one). **World** = a Baby's home surface.
  **Family** = the roster of loved ones (was "Persona"), each with relationship +
  nicknames (per baby–person pair) + photos + voice clips. **Character** = purely
  fictional, no photos/voice, free.
- Multi-baby rule: Family roster is shared by default across a Household's babies;
  a baby may get its own separate roster if indicated at add-time.
- Design system: cream/Baloo 2 + Nunito/lavender+amber, rounded, soft shadows —
  still the brand canon later PRDs (v15) build native polish on top of.
- Monetization was deliberately deferred here (decided later, see PRD v12/v20).
